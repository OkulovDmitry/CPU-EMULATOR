# Введение
Данный проект посвящен написанию собственной виртуальной машины симулирующей написание работы процессора. Проект состоит из трез программ: ассемблер, дизассемблер, машина.

## Возможности

* **Ассемблер**
* **Дизассемблер**
* **Машина**

## Структура проекта
> * 'isa.h / .c' - Instruction Set Architecture, эта модель описывает что умеет делать процессор, задает его команды, регистры, задет способ обращения к процессору
<details>
Для трансляции ассемблерного кода во внутреннее представление процессора 'isa'. Он связывает текстовые **мнемоники** команд с их **внутренними идентификаторами (Opcodes)** и поддерживаемыми **типами аргументов**.

| Идентификатор (Opcode) | Мнемоника | Аргументы (Флаги типов) | Количество аргументов | Описание команды |
| :--- | :--- | :--- | :--- | :--- |
| `CMD_HLT` | `"HLT"` | `0` | `0` | Остановка процессора / завершение программы. |
| `CMD_PUSH` | `"PUSH"` | `BIT_IMM \| BIT_REG` | `0` | Положить значение (число или регистр) на вершину стека. |
| `CMD_ADD` | `"ADD"` | `0` | `0` | Сложение (работает со стеком). |
| `CMD_SUB` | `"SUB"` | `0` | `0` | Вычитание. |
| `CMD_MUL` | `"MUL"` | `0` | `0` | Умножение. |
| `CMD_DIV` | `"DIV"` | `0` | `0` | Деление. |
| `CMD_OUT` | `"OUT"` | `0` | `0` | Вывод значения в консоль. |
| `CMD_POP` | `"POP"` | `BIT_REG` | `0` | Извлечь значение со стека в регистр. |
| `CMD_JMP` | `"JMP"` | `BIT_IMM` | `1` | Безусловный переход по адресу (метке). |
| `CMD_JA` / `CMD_JAE` | `"JA"` / `"JAE"` | `BIT_IMM` | `1` | Условные переходы: Выше (Above) / Выше или равно. |
| `CMD_JB` / `CMD_JBE` | `"JB"` / `"JBE"` | `BIT_IMM` | `1` | Условные переходы: Ниже (Below) / Ниже или равно. |
| `CMD_JE` / `CMD_JNE` | `"JE"` / `"JNE"` | `BIT_IMM` | `1` | Условные переходы: Равно (Equal) / Не равно. |
| `CMD_CALL` | `"CALL"` | `BIT_IMM` | `1` | Вызов подпрограммы (переход с сохранением адреса возврата). |
| `CMD_RET` | `"RET"` | `0` | `0` | Возврат из подпрограммы. |

</details>
> * 'bytecode.h / .c' - содержат функции ввода-вывода байт-кода
<details>
> * bytecode_read(const char* path, int* size) - производит полное чтение файла с байт-кодом и производит его запись в Elem_t*
> * bytecode_write(const char* path, const code_t* code, const int size) - производит запись байт-кода в файл
</details>
